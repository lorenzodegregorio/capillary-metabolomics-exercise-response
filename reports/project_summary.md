# Project Summary

## Context

This project investigates whether repeated-baseline capillary blood metabolomics can improve the interpretation of acute metabolic responses to maximal exercise.

The original study involved healthy adult participants undergoing cardiopulmonary exercise testing, with capillary blood samples collected at two resting baseline timepoints and immediately after exercise.

## Analytical idea

The key methodological idea is to compare post-exercise metabolite changes not only against a single baseline, but also against short-term resting variability estimated from two repeated baseline samples.

This makes it possible to distinguish broad group-level changes from metabolite responses that more clearly exceed baseline-derived methodological noise.

## Methods

The analysis included:

- metabolomics data preprocessing;
- metabolite-level quality control;
- baseline reproducibility analysis;
- PCA and exploratory multivariate analysis;
- signal-to-noise response ranking;
- participant-level determinant analysis;
- predictive modelling of VO₂peak.

## Notes

The repository is a public portfolio version of the project. It does not include raw biomedical data or unpublished manuscript files.
